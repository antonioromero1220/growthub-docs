## Common Workflows

### Content Creation Workflow
1. Create new chat in **Content Gen** project
2. Select `@Content agent` or `@copywriting agent`
3. Provide brief and context
4. Iterate with follow-up messages
5. **Download** final thread for records
6. **Archive** when complete

### Development Workflow
1. Start chat in appropriate project folder
2. Select **Gemini 3.0 Flash** or **Claude Haiku 4.5** (Coding capability)
3. Paste code or describe problem
4. Iterate on solutions
5. **Rename** thread with descriptive title
6. Keep active or **Archive** when resolved

### Research Workflow
1. New chat in **Inbox** or create dedicated project
2. Select **GPT-5 Mini** (Web Search capability)
3. Ask research questions
4. AI provides sourced information
5. **Download** for documentation
6. Move to appropriate project or **Archive**

### Multi-Agent Campaign
1. `@Content agent` → Write blog post
2. `@copywriting agent` → Create social media posts
3. `@Slides generation agent` → Build presentation
4. `@YouTube thumbnail agent` → Design thumbnail concept
5. **Download** entire thread as project documentation
6. **Archive** campaign thread when launched

## Tips and Tricks

### Productivity Boosters

**Keyboard Shortcuts**
- `Cmd/Ctrl + N` - New chat
- `Cmd/Ctrl + B` - Toggle sidebar
- `@` - Trigger agent selector
- `Enter` - Send message
- `Shift + Enter` - New line

**Quick Navigation**
- Use **Recent** folder for cross-project recent work
- **Chats view** for chronological access
- **Projects view** for focused work
- Search coming soon for instant access

**Smart Organization**
- Rename threads immediately with descriptive titles
- Archive daily to keep workspace clean
- Use project folders to group related work
- Download important threads for backup

### Power User Features

**Model Switching**
- Switch models mid-conversation for different perspectives
- Use Web Search model for research, then Coding model for implementation
- Try multiple models for complex problems

**Agent Chaining**
- Use multiple agents in sequence within same thread
- Each agent contributes expertise to project
- Maintains context across agent switches

**Thread Templates** (Manual)
- Save downloaded threads as templates
- Reuse successful prompt structures
- Build personal prompt library

## FAQ Highlights

**Q: Which model should I use?**  
A: See [Model Selection Guide](./MODEL_SELECTION.md#model-selection-best-practices) for task-specific recommendations.

**Q: How do I use custom agents?**  
A: Type `@` in chat or click the 🧠 icon. See [Custom Agents Guide](./CUSTOM_AGENTS.md#how-to-use-custom-agents).

**Q: Where did autopilot and sandbox go?**  
A: They're merged into the unified interface. See [Unified Chat Interface](./UNIFIED_CHAT_INTERFACE.md#differences-from-legacy-interfaces).

**Q: How do I organize my conversations?**  
A: Use project folders and thread management. See [Project Organization](./PROJECT_ORGANIZATION.md) and [Thread Management](./THREAD_MANAGEMENT.md).

**Q: Can I recover deleted threads?**  
A: No, deletion is permanent. Always download important threads first. See [Thread Management - Delete](./THREAD_MANAGEMENT.md#delete-thread).
